# GPUI Desktop Implementation Plan

> **For agentic workers:** implement the approved chat plan in this worktree, tracking actual checks below.

**Goal:** Replace the webview application with the same speech workflow in Rust/GPUI.
**Architecture:** Framework-independent Rust storage and an ordered service worker feed a GPUI view. The existing inference and save workers remain responsible for expensive work.
**Tech Stack:** GPUI Kit 0.9, rodio, rfd, Symphonia, rubato, image/resvg, cargo-packager.
**Spec:** ../specs/2026-11-06-gpui-design.md

## Global Constraints

- Preserve ZIP/YAML fields and IDs, existing models and engine/server behavior.
- Remove Tauri/React upfront. No parallel frontend. Desktop runtime entirely Rust.
- Windows x64, macOS ARM64 15+, Linux x64; Cargo owns app and development tasks; Python export remains.

## Review Focus

- A failed save must not close the window or discard the old project.
- Switching projects must not admit stale worker results into a new session.
- IME composition must not trigger generation or discard composed text.
- Failed regeneration must retain prior audio and stop must finish the current row.
- Bundled models must resolve independently of the working directory.
