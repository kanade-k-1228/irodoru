# アプリメニューと複数ウィンドウ

ロゴをヘッダ左端に戻し、クリックで新規ウィンドウ、新規プロジェクト、プロジェクトを開く、保存、テーマ切替、環境設定、このアプリについて、ウィンドウを閉じるを表示する。プロジェクト操作とテーマの独立したヘッダボタンはメニューへ移す。右端のウィンドウ操作とタイトルのドラッグは維持する。

OSのネイティブメニューとHTMLのメニューを比較し、ロゴから開く一貫した操作とモバイル対応のためHTMLを採用する。キーボード移動、Escape、外側クリック、フォーカス復帰に対応する。環境設定は既存のテーマ設定を扱い、未実装の項目を並べない。

新規ウィンドウは別プロジェクト用とする（実装側の仮定）。各ウィンドウが台本、キャラクタ、プレビュー、生成バッチ、ZIP保存ワーカーを所有する。推論エンジンは共有する。同じZIPの同時編集を拒否し、ウィンドウ破棄時に状態を解放する。保存状態イベントは対象ウィンドウにだけ送る。モバイルにはウィンドウ操作項目を表示しない。

検証: 既存のテスト・型検査・ビルド、複数プロジェクトの保存分離とZIP所有権のテスト、メニューのマウス・キーボード操作、テーマ、ダイアログ、狭い画面での表示を確認する。
